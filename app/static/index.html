Numbers come from YouTube by themselves (Data API + Analytics API) and refresh every few hours; they run 1 to 2 days behind. You can change slot, type, project and notes (kept across syncs). Engaged % = engaged views / views, a proxy: YouTube's "Viewed vs swiped away" isn't available to the API, so type it into the last-but-one column from Studio if you want it.
